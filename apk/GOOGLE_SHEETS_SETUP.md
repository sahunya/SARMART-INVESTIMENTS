# Link SARMART INVESTIMENTS to Google Sheets

1. Sign in to Google as **sammwaww@gmail.com**, then create a blank Google Sheet named **SARMART INVESTIMENTS Ledger**.
2. In that sheet, choose **Extensions → Apps Script**.
3. Replace the starter code with the contents of `google-apps-script.gs`.
4. Set `API_TOKEN` to a long private password of your choice.
5. Select **Deploy → New deployment → Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
6. Copy the deployed **Web app URL**.

Send the Google Sheet link and Web app URL here. I will then connect the app so every added or deleted transaction is saved to the sheet straight away and appears on other devices.

Do not share the private API token in chat. It will be entered locally when connecting the app.
